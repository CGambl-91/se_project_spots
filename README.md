# Project 3: Spots

An image sharing site.

## Description

Spots is a responsive social media-style web application that allows users to create, view, and interact with photo cards. Built using HTML, CSS, and JavaScript, the project focuses on dynamic user interactions, including editing profile information, adding new posts through modal forms, liking and unliking cards, and deleting posts. Throughout the development process, I implemented reusable JavaScript functions, form validation, event handling, and DOM manipulation to create a seamless user experience. The project strengthened my understanding of responsive web design, component-based development practices, and interactive front-end functionality while demonstrating my ability to build user-friendly applications from design specifications.

## Tech Stack

- HTML
- CSS
- Responsive Design
- CSS Grid
- Media queries
